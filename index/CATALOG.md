# Индекс материалов (лекции + тест)

Сгенерировано для быстрого поиска без повторного чтения PDF/DOCX.

## Как пользоваться

- Полные тексты: `extracted/*.txt`
- Машиночитаемый каталог: `index/catalog.json`
- Вопросы теста: `index/questions_raw.json` (50 шт., без ключа ответов)
- Этот файл: обзор тем и покрытие

## Сводка

- Всего файлов: **14** (13 лекций/процедур + 1 тест)
- Дубликат: `Урок 4.pdf == Урок 3-4.pdf`
- Нужен OCR: `Клизмы.pdf`, `Постановка компресса.pdf`, `нательного белья)..pdf`, `частично: волосами. Кормление. Пролежни)..pdf`

### Кривые имена файлов

- `д.pdf` → **Измерение АД**
- `с.pdf` → **ЛС и инъекции**
- `волосами. Кормление. Пролежни)..pdf` → **Опрелости / судно / пролежни / кормление (имя обрезано)**
- `нательного белья)..pdf` → **Смена белья (имя обрезано)**

### Пробелы относительно теста

- лабораторные и инструментальные исследования (Q31–Q38) — отдельной лекции нет
- реанимация / клиническая и биологическая смерть (Q39–Q46, Q50) — отдельной лекции нет
- ключ правильных ответов в docx отсутствует
