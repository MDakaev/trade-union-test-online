# Changelog

## 1.1.0 — 2026-08-10

### Added
- Каталог тестов на GitHub Pages: итоговый, уход, первая помощь, лекарства/инъекции
- Три новых банка из промежуточных контролей (best-effort ключи ответов)
- Хаб `/quiz` и маршруты `/quiz/:quizId` с раздельным сохранением попыток

### Changed
- GitHub Pages — основной публичный канал (прогресс в localStorage)
- Workflow Pages собирает monorepo из корня (`npm run build:demo`)

## 1.0.0 — 2026-08-06

### Added
- Адаптивное PWA для учеников (уроки, карточки, тесты, повторение)
- Демо-админка: аналитика, ученики, CMS, настройки бренда
- PHP API: приглашения, аккаунты, прогресс, CMS, аудит
- Курс «Младшая медсестра по уходу за больными» на основе лекций школы
- GitHub Pages demo build + документация для Timeweb/Beget
- Индекс исходных PDF/DOCX (`extracted/`, `index/`)
