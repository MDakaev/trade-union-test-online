# Handoff checklist for selling / transferring Trade Union LMS

## Before demo to client
- [ ] `npm run build` succeeds
- [ ] GitHub Pages demo opens on mobile and desktop
- [ ] Invite → register → lesson → quiz flow works on staging
- [ ] Admin can create invite, see students, edit lesson status
- [ ] Course questions with `needs_review` are hidden from final exam or approved
- [ ] Admin password changed from installer default
- [ ] HTTPS + daily backups enabled on Timeweb/Beget

## Package delivered
- [ ] Source repository access
- [ ] `docs/DEPLOYMENT.md` followed once successfully
- [ ] `.env.example` filled for production
- [ ] First admin account created
- [ ] `content/course/course.json` imported
- [ ] LICENSE / commercial terms agreed

## Support boundary (v1)
Included: install guide, backup/restore, known troubleshooting.
Not included unless contracted: new medical content writing, custom branding beyond config, server admin outside shared hosting panel.
