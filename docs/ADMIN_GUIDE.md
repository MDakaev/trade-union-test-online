# Руководство администратора

## Первый вход

1. Получите логин/пароль от установщика (`create-admin.php`).
2. Откройте сайт → Войти.
3. Переключитесь в админку (в production роль `admin` открывает `/admin`).

## Приглашения учеников

1. **Ученики → Создать код**
2. Укажите группу, лимит использований, срок.
3. Скопируйте код **сразу** — полный код показывается один раз.
4. Выдайте код ученику. Он создаст логин и пароль сам.

Код можно отозвать в любой момент.

## Ученики

- Поиск по ФИО/группе
- Просмотр прогресса, среднего балла, ошибок
- Блокировка и сброс пароля
- Экспорт списка

## Материалы (CMS)

- Модули и уроки с drag-and-drop порядком
- Статусы: **Черновик / На проверке / Опубликован**
- Карточки и вопросы с объяснениями
- Импорт/экспорт JSON курса

Не публикуйте материалы со статусом `needs_review` без проверки преподавателя.

## Оценки

По умолчанию:
- 90–100% → 5
- 75–89% → 4
- 60–74% → 3
- <60% → 2

Меняется в **Настройки → Оценивание**.

## Бренд

В настройках: название, цвет, контакт. Для white-label продажи другому клиенту достаточно сменить конфиг и импортировать курс.
