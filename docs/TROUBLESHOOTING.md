# Troubleshooting

## Сайт открывается, API нет

- Проверьте rewrite `/api` → `public/index.php`
- Откройте `/api/health` — должен вернуть JSON `{ "ok": true }`
- Смотрите `apps/api/storage/logs/`

## 500 на API

- Права на `storage/` (запись)
- Корректный `.env` и доступ к MySQL
- Версия PHP ≥ 8.2

## Ученик не может зарегистрироваться по коду

- Код истёк / исчерпан / отозван
- Регистр не важен, но пробелы и кириллица «похожие» символы — нет
- Создайте новый код в админке

## Прогресс не синхронизируется

- В production нужен логин (не demo localStorage)
- Проверьте SPA_ORIGIN = точный origin фронтенда
- Cookie Secure требует HTTPS

## Фронтенд белый экран на GitHub Pages

- Неверный `VITE_BASE_PATH` (должен совпадать с именем репозитория)
- Смотрите Console: 404 на `/assets/...`

## «Сломалось после обновления»

1. Восстановите последний SQL-бэкап
2. Задеплойте предыдущий `dist`
3. Напишите в issue с выводом `/api/health` и временем инцидента

Если проблема повторяется — откатите контент через импорт предыдущего `course-backup.json`.
