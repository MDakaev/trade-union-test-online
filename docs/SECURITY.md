# Безопасность

## Модель доступа

- Ученик входит по логину/паролю после одноразового invite-кода
- Invite-коды хранятся **только как хэш** (как пароли)
- Админ и ученик — разные роли; проверки на сервере

## Сессии

- Cookie: `HttpOnly`, `Secure` (prod), `SameSite=Lax`
- CSRF-токен для мутирующих запросов
- Rate limit на `/api/auth/login` и `/api/auth/register`

## Пароли

- Argon2id (`password_hash` / `PASSWORD_ARGON2ID`)
- Минимум 8 символов при регистрации
- Сброс пароля — только админом (нет публичного e-mail reset в v1)

## Контент и demo

- GitHub Pages demo не содержит реальных кодов, паролей, ФИО учеников
- Исходные PDF можно исключить из публичного зеркала (private repo / .gitattributes export-ignore)

## Рекомендации владельцу

1. Смените пароль админа сразу после установки
2. Не публикуйте `.env`
3. Включайте HTTPS всегда
4. Отзывайте неиспользованные invite-коды
5. Делайте бэкапы перед массовым импортом курса
